# Изображения и голос Финна

## Оформление

`public/images/obsidian-dice.jpg` — фотография кубиков, предоставленная владельцем проекта в качестве визуального референса. Сохранена без редактирования. Основные цвета интерфейса — чёрный и бордово-красный; текст светлый, акценты малиновые. Векторные карта, пейзажи, Финн и кубики созданы для интерфейса Dicebound.

## Озвучка

В `public/audio/finn/` находятся 21 готовая русская реплика. Варианты учитывают роль ведущего или игрока. Аудио воспроизводится локально, без внешнего сервиса, ключей и установленного русского системного голоса. Выключение звука запоминается в браузере. При переходе к следующему шагу или закрытии экскурсии текущая реплика останавливается.

Реплики синтезированы локально с [Piper](https://github.com/OHF-Voice/piper1-gpl), версия 1.8.0, моделью [ru_RU-denis-medium](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/denis/medium). [Карточка модели](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/denis/medium/MODEL_CARD) указывает набор данных CC0. Сам движок Piper распространяется под GPL-3.0; движок и веса модели не включены в приложение. Это синтетический голос стандартной модели.

Для запуска сайта Python и Piper не нужны. Чтобы перезаписать изменённые реплики:

1. Изменить текст в `lib/guide-content.ts`.
2. Выполнить `node scripts/finn-transcript.mjs`.
3. В отдельном Python-окружении установить `piper-tts==1.8.0`.
4. Скачать модель `.onnx` и соседний `.onnx.json` из источника выше в локальную папку вне репозитория.
5. Выполнить `python scripts/render-finn.py --model "путь/ru_RU-denis-medium.onnx"`.
6. Выполнить `node scripts/finn-transcript.mjs --check` и прослушать обновлённые реплики.

Скрипт создаёт WAV и манифест с длительностями и SHA-256 текста и аудио. Контрольная сумма использованной модели: `879bc365cb14d1380e3f5ed6044162ccf54c99f6161871569b7f830aec3ce841`.

## Шрифт заголовков

Cormorant SC Bold (700), с латиницей и кириллицей, используется для логотипа и заголовков. Файл обслуживается локально из public/fonts/. Источник: https://github.com/google/fonts/tree/main/ofl/cormorantsc. Лицензия SIL Open Font License 1.1 приложена в public/fonts/OFL-CormorantSC.txt. Основной текст использует системный шрифт.

## Карта мира и стол мастера

`public/images/world-map-desk.png` — оригинальная иллюстрация, созданная встроенным генератором изображений для Dicebound. Используется как фон главного экрана. Поверх неё находятся доступные с клавиатуры кнопки локаций, которые выбирают соответствующий мир в каталоге.

Исходный запрос на генерацию сохранён в `docs/world-map-art-prompt.txt`. Фотография кубиков сохранена в проекте как прежний визуальный материал.
