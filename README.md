# Dicebound

Локальный прототип платформы для поиска отряда и настольных ролевых игр прямо в браузере.

## Запуск

Требуется Node.js 22.13 или новее. Откройте терминал в папке скачанного проекта:

```powershell
npm.cmd ci
npm.cmd run dev
```

Открыть **http://127.0.0.1:5173**. Остановка — `Ctrl+C` в терминале. На macOS/Linux используйте `npm` вместо `npm.cmd`.

Для проверки двух игроков откройте сайт в обычном и приватном окне браузера (или в двух разных браузерах), задайте разные имена через «Мой персонаж» и войдите в одну комнату. Две обычные вкладки одного профиля браузера используют одного персонажа.

## Что работает

- Каталог комнат, поиск, фильтры по опыту и миру, свободные места, избранное.
- Создание комнат на 2–6 участников, гостевой профиль и класс персонажа.
- Общая карта 20 × 14 клеток. Персонажи перемещаются кликом, перетаскиванием или стрелками клавиатуры после фокусировки жетона.
- Игрок двигает только своего героя; ведущий — любого. Проверяются границы карты и занятые клетки.
- Чат, сообщения ведущего, история игры и бросков.
- Броски d4, d6, d8, d10, d12, d20, количество кубиков и модификатор. Сервер использует `crypto.randomInt`; все игроки получают один результат.
- Общие здоровье, порядок ходов и раунды. Управление ходом доступно ведущему.
- Обновления через Server-Sent Events (SSE), автоматическое переподключение с полной актуальной комнатой.
- Сохранение комнат, сообщений, персонажей и гостевых сессий в `data/dicebound.json`. Файл создаётся автоматически и исключён из Git.
- Три стартовые комнаты без вымышленных участников. Первый вошедший становится ведущим. При его выходе роль переходит следующему участнику.
- Адаптивный интерфейс в графитовых, бордовых и золотых оттенках: фото кубиков, векторные иллюстрации и карта. Все изображения и реплики обслуживаются самим приложением.
- Финн — анимированный проводник с русской озвучкой, подсветкой кнопок, выключением звука и повтором реплик.

«Мои приключения» показывает комнаты, где состоит текущий герой. Возврат в каталог сохраняет место; кнопка «Покинуть отряд» освобождает его. Избранное хранится в текущем браузере. Ссылка комнаты работает, пока запущен этот локальный сервер.

## Команды

```powershell
npm.cmd run dev       # Сервер приложения и API
npm.cmd test          # Интеграционные проверки с двумя независимыми сессиями
npm.cmd run typecheck # Проверка TypeScript
npm.cmd run build     # Сборка интерфейса
npm.cmd start         # Запуск собранного приложения
```

Dev и production запускаются по очереди: оба используют порты 5173 и 3001. Production также использует внутренний порт 5174.

## Структура

- `app/page.tsx` — каталог, лобби, чат, интерфейс игрового стола.
- `app/globals.css`, `app/obsidian-theme.css` — тема и адаптивные стили.
- `components/battle-map.tsx` — оригинальная SVG-карта и управление фишками.
- `components/landscape.tsx` — оригинальные иллюстрации миров.
- `lib/game-types.ts` — типы игрового состояния.
- `server/game.mjs` — Node.js HTTP API, SSE, серверные броски и хранение данных.
- `server/game.test.mjs` — интеграционные проверки реального API и двух SSE-подключений.
- `scripts/dev.mjs`, `scripts/start.mjs` — запуск локальных процессов.

Интерфейс: React 19, TypeScript, Vinext/Vite. Основа проекта взята из Sites starter; локальная версия не зарегистрирована и не опубликована в Sites. Сервер игры использует только стандартные модули Node.js.

## Границы первой версии

Это локальный виртуальный игровой стол с ведущим-человеком, а не полная автоматизация правил D&D. Классы пока описательные, здоровье условно начинается с 20, порядок ходов задаётся порядком вступления. Стены на карте декоративные: столкновения с ними, дальность и видимость не рассчитываются. Три темы используют общий план святилища с вариацией оформления.

Пока нет голосовой связи, ИИ-ведущего, полноценных листов персонажей, учётных записей с паролем, приватных приглашений, поиска друзей, редактора/загрузки карт, списка присутствующих онлайн и публичного размещения. Участники в карточке — записавшиеся в отряд, а не гарантированно онлайн.

Сервер слушает только `127.0.0.1`: текущая ссылка предназначена для этого компьютера. Для игры с друзьями с других устройств следующим этапом нужны размещение приложения, HTTPS, полноценная авторизация и база данных. JSON-хранилище рассчитано на один локальный процесс. Гостевые сессии не заменяют систему учётных записей.

Не публикуйте `data/dicebound.json`: он содержит историю комнат и локальные сессии. Для новой публичной версии потребуется отдельная настройка доступа и хранения данных.

Также можно запустить start-dicebound.cmd двойным щелчком из папки проекта. Оставьте открывшееся окно работающим и перейдите на http://127.0.0.1:5173.


## Финн — проводник по интерфейсу

Кнопка со знаком вопроса вызывает анимированного Финна. Он появляется рядом с конкретной кнопкой или разделом, подсвечивает его и объясняет назначение. В каталоге и за игровым столом разные экскурсии. Доступны «Далее», «Назад», «Пропустить», стрелки клавиатуры и Escape. При закрытии восстанавливаются прокрутка и фокус; анимация учитывает настройку уменьшения движения.

Компонент и оформление: `components/guide-tour.tsx`, `components/guide-tour.css`. Элементы страницы привязаны через `data-tour`. Превью: `docs/finn-guide-preview.jpg`.

Тексты хранятся в `lib/guide-content.ts`, 21 готовая русская аудиореплика — в `public/audio/finn/`. При смене шага или закрытии экскурсии голос останавливается. Настройка звука запоминается. Устанавливать русский системный голос не требуется. Источники материалов и перезапись реплик описаны в [docs/assets.md](docs/assets.md).

## GitHub и VS Code

Репозиторий: [RUsIk65/Dicebound](https://github.com/RUsIk65/Dicebound). Откройте корневую папку проекта в VS Code и раздел Source Control (`Ctrl+Shift+G`). Авторизация GitHub выполняется через браузер при первой отправке.

Для следующих изменений: проверьте diff, добавьте нужные файлы в Stage, введите описание, нажмите **Commit**, затем **Sync Changes**.

Публикуются исходники, `public/`, конфигурация, `package.json`, `package-lock.json` и документация. `.gitignore` исключает зависимости, сборки, `.env`, логи и `data/` с локальной историей и сессиями. Готовые аудиофайлы включены; модели и временные инструменты синтеза исключены.

GitHub хранит код. Публикация репозитория сама по себе не запускает игровой сервер и не делает локальную ссылку доступной друзьям.


При открытии сайта появляется только небольшая текстовая подсказка у кнопки помощи, без звука. Она исчезает при любом клике на странице. «Показать подсказки» закрывает окно и запускает экскурсию с Финном. «Пропустить», крестик, Escape и завершение экскурсии немедленно останавливают аудио и отменяют его загрузку; переходы между шагами прерывают предыдущую реплику.

При первом запуске после переименования старое хранилище автоматически переносится в `data/dicebound.json`. Сохраняются комнаты, история и гостевые сессии. Избранное и настройка озвучки в браузере также совместимы с предыдущей версией.
